# Human RTTM annotation and adjudication — metadata-only v1

This is **human review scaffolding**, not a benchmark certification tool.
It is a companion to rights-clear source intake v2 in
[`diarization-rights-clear-v2.md`](diarization-rights-clear-v2.md).
The v1 engineering WAVs/RTTMs and provenance manifest in PR #154 are
**unverified for voice identity, speech boundaries, and redistribution**.
Do not publish, relabel, regenerate or merge them as reference ground truth.

## Review process (external humans; separate approvals)

1. **Rights gate:** independently verify the recording licence, performer
   release, derivative-mixing permission and public pseudonyms for each
   source. Keep consent documents and real names private. Run the separate
   rights-intake v2 metadata and WAV preflight *when approved*; this tool
   checks only the v2 **metadata schema and its byte-for-byte SHA-256**,
   not the voice files or the authenticity of rights evidence.
2. **Two blinded annotators:** independently inspect the authorised clip
   without seeing model predictions, each other's labels, or script-track
   placement as authoritative speech boundaries. Record active speech
   intervals at integer-millisecond resolution, split internal pauses,
   distinguish the same approved speaker consistently, and enter every
   concurrent speaker as a separate segment. Label backchannels explicitly.
   Omit silence instead of using an unknown speaker.
3. **Independent adjudicator:** compare both reviewers' interval-by-interval
   active-speaker sets. Explain and reference **every span** where those sets
   differ. Do not silently modify areas where reviewers agree. Manually
   examine all disagreement spans, with particular attention to boundaries
   separated by over **50 ms** and escalation over **100 ms**. Those are
   *proposed manual review tolerances*, not model scores or automatically
   enforced estimates of annotation accuracy. Verify identity and overlap
   independently of the original script.
4. **Provenance:** retain immutable independent reviewer records, individual
   opaque evidence references, the final adjudicator evidence record, the
   exact rights-intake metadata SHA, and the asserted recording SHA.
   Cross-check hashes against originals in a separate protected evidence
   workflow. Do not store private identities, audio, model predictions or
   signed releases in this public-facing repository.
5. **Publication gate:** independent human verification of rights, speaker
   identities, phonetic boundaries and a documented corpus-use grant is
   required before exporting benchmark ground truth or reporting model
   DER/JER. A successful CLI check alone proves none of these.

## Metadata bundle contract

The preflight input is a separately held JSON bundle, **not a new
recording/RTTM generated by the script**. Minimal shape (example only;
replace placeholders using the correct consented intake and real human
review artefacts; never publish sensitive evidence):

```json
{
  "bundle_version": 1,
  "fixture_set_id": "consented_set_01",
  "case_id": "overlap_2spk",
  "rights_intake_sha256": "<64 lowercase hex characters>",
  "recording_sha256": "<64 lowercase hex characters>",
  "rights_review_evidence_id": "rights_review_01",
  "reviewers": [
    {
      "reviewer_id": "reviewer_alpha",
      "review_evidence_id": "review_log_alpha",
      "independent": true,
      "model_output_seen": false,
      "segments": [
        {"start_ms": 0, "end_ms": 3000, "speaker_id": "spk_01"},
        {"start_ms": 2000, "end_ms": 4000, "speaker_id": "spk_02"}
      ]
    },
    {
      "reviewer_id": "reviewer_beta",
      "review_evidence_id": "review_log_beta",
      "independent": true,
      "model_output_seen": false,
      "segments": [
        {"start_ms": 0, "end_ms": 2900, "speaker_id": "spk_01"},
        {"start_ms": 2000, "end_ms": 4000, "speaker_id": "spk_02"}
      ]
    }
  ],
  "adjudication": {
    "adjudicator_id": "reviewer_gamma",
    "review_evidence_id": "review_log_gamma",
    "segments": [
      {"start_ms": 0, "end_ms": 3000, "speaker_id": "spk_01"},
      {"start_ms": 2000, "end_ms": 4000, "speaker_id": "spk_02"}
    ],
    "decisions": [
      {
        "start_ms": 2900,
        "end_ms": 3000,
        "reason": "boundary",
        "evidence_id": "decision_001"
      }
    ]
  }
}
```

The bundle needs one case and its exact declared rights-intake v2 metadata
file. Both reviewer records and the final record are **half-open** intervals
`[start_ms, end_ms)`, sorted by start/end/speaker and limited to the
rights-intake case roster. Reviewers may overlap **different** speakers,
but cannot overlap or duplicate the same speaker's turns. The automated
decision spans are maximal adjacent intervals where reviewer active-speaker
sets disagree. Each such span requires exactly one evidence-linked
decision with matching start/end. A final annotation may disagree with either
reviewer *within* such a span, but cannot silently alter an agreed region.

The CLI accepts at most 128 KiB per JSON input and 256 segments per
reviewer/final record. Invalid JSON, duplicated object keys, invalid time
units, reused evidence IDs, unknown speakers, mismatched intake hashes,
missing rights-attestation metadata and unsupported review states fail
closed. Rights/source digests in the bundle are *claims*: this tool does
not open recordings, verify human identity, authenticate licences, or
confirm that an asserted recording hash matches audio bytes.

## Offline checks (no WAV, model or network reads)

```bash
python3 -B scripts/validate-diarization-adjudication.py \
  --intake-v2 /secure/review/intake-v2.json \
  --bundle /secure/review/overlap_2spk.review.json
```

Default output is a JSON **metadata-consistency-only** report with
`publication_ready: false` and explicit `source_audio_opened: false`.
The optional stdout-only draft format:

```bash
python3 -B scripts/validate-diarization-adjudication.py \
  --intake-v2 /secure/review/intake-v2.json \
  --bundle /secure/review/overlap_2spk.review.json \
  --format rttm
```

It prints `SPEAKER` RTTM lines with three-decimal second fields and an
`# UNVERIFIED` header; it does **not** write files or certify that the
labels are correct. Exact millisecond half-open boundaries are preserved
and concurrent speakers remain separate rows. Save or use the preview
only in a separately approved protected annotation workflow.

## Synthetic CI checks

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -B -m unittest discover \
  -s test/unit -p test_diarization_adjudication.py -v
node --test test/unit/diarization-adjudication-scoring.test.mjs
```

These tests create only ephemeral text/JSON metadata, with fabricated
opaque references and speaker intervals. They do not open the historical
WAV fixture files, inspect any live recording, download anything, load a
model, invoke inference, deploy or restart a service. Existing benchmark
and source-audio rights gates remain unchanged.
