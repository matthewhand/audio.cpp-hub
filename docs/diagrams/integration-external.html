DP INTEGRATION · 外部集成

hub 与外部系统的接线：入站协议、出站下载源、回环引擎

左侧是 OpenAI 兼容客户端，右侧是三个公网下载源与回环引擎。每条线都标注方向、协议与端口；有 gated 仓库的下载源需要 bearer token，且两条已知失败边界（multipart 路由、ModelScope 仅镜像一个仓库）在图中明示。

KEY POINT

三个方向，三种协议

  • 入站：GET /v1/models 与 POST|PUT /v1/*（如 /v1/audio/speech），HTTP :18080，仅 JSON body 才能提取顶层 model。
  • 回环：hub → 引擎 HTTP 127.0.0.1:18090，与 Web UI 的 /api/tasks 链路共用同一串行队列。
  • 出站：权重下载 HTTPS :443，按 hfEndpoint 或不带 scheme 的 source:"modelscope" 选择源。

BOUNDARY · 已知失败边界

认证与失败

  • gated 仓库：POST /api/downloads 需传 HF token（bearer）；缺失或无效 → DOWNLOAD_AUTH。token 以明文存 data/downloads/<id>/task.json（目录 0700 / 文件 0600，API 输出剔除）。
  • /v1/* 的 multipart 无法提取 model → 400（图中 blocked 线）。
  • source:"modelscope" 仅映射 HereIsMark/<repo>；当前只镜像 audio.cpp-gguf，其它包 → REMOTE_NOT_FOUND。
