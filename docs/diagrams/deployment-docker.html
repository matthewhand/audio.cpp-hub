Docker 部署（AMD / Vulkan）

单容器跑 hub 与一个 audiocpp_server 子进程：宿主设备与目录经 --device / bind mount 传入，仅发布 18080/tcp，子进程只在容器 loopback 上监听。

KEY POINT

仅发布一个端口

容器只发布 18080/tcp；子进程 18090 仅在容器 loopback，外部无法直达。

BOUNDARY

宿主资源只读

bin 与 .gguf 以 :ro 挂载；GPU 经 --device 透传，Mesa RADV 来自镜像。
