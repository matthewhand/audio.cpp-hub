实例与任务状态机

hub 只编排外部 audiocpp_server 子进程：实例从 STARTING 经 1s 一次的健康轮询进入 READY，120s 未就绪即 FAILED；任务按实例串行排队，RUNNING 阶段取消只中断 hub 侧等待。

KEY POINT

就绪 ≠ 模型已进显存

READY 只代表 GET /health 通过；真正的加载由启动脚本的预热请求（RIFF 校验）确认。

BOUNDARY
