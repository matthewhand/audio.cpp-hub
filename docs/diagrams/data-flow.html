DATA FLOW · 数据流

数据如何流入、变换、持久化与流出

客户端上传与引用经 hub 编排进入引擎推理，结果分别落入历史、任务状态与权重目录；历史无自动淘汰，任务/下载状态重启回放。

KEY POINT

历史无淘汰

data/history/<modelId>/ 是用户资产：index.jsonl 只追加，结果 wav 与参考音频快照自包含；无数量/容量上限，只由用户手动删除。

RETENTION

状态重启回放

data/tasks/<id>.task.json 与 data/downloads/<id>/task.json 原子落盘；hub 重启后回放，进行中任务标记 CANCELLED，下载从分段断点续传。
