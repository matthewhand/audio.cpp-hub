OpenAI 兼容代理链路

请求体流式落盘 proxy-cache → 逐字节提取 model → 按服务名路由到 READY 实例 → 响应分块回写。

KEY POINT

请求体先落盘、model 后路由

body 流式写入 run/proxy-cache/（超 proxyMaxBodyBytes 返回 413），再用逐字节 extractor 取顶层 "model"，按服务名查 READY 实例；不存在 404、启动中 409。

KNOWN LIMIT

multipart 无法提 model

extractor 只识别 JSON；multipart/form-data 请求体提取不到 model，会返回 400。响应状态码 / Content-Type 透传，逐块 Flush 兼容 SSE。
