SEQUENCE · TTS 异步任务

TTS 异步任务链路

Web UI 提交 → 每实例串行队列 → audiocpp_server 生成 → 音频写入历史 → 2s 轮询播放。

KEY POINT

每实例串行、异步不阻塞

POST /api/tasks 立即返回 202 与排队位置；TaskManager 为每个实例起一个单线程 executor，同实例任务串行执行，无执行时长上限。

DATA PATH

TTS taskId = 历史 id

引擎响应流式落盘后由 extractAudio 提取顶层 "audio" 写成 data/history/<modelId>/<taskId>.wav，并追加 index.jsonl；前端用 /api/history/.../audio 播放。
