audio.cpp-hub 概览

一个 Go 单二进制管理面板：浏览器与 OpenAI 兼容客户端接入，hub 编排外部 audiocpp_server 子进程，权重与工作区落在本地存储。

KEY POINT

hub 不加载模型

hub 进程只做编排，模型始终在独立的 audiocpp_server 子进程中运行。

BOUNDARY

仅本机 / 局域网

无鉴权设计；子进程绑定 127.0.0.1，外部访问请走反向代理 + HTTPS。
