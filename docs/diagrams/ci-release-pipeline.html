CI / RELEASE · .github/workflows

CI 与发布流水线

PR 走 ci.yml 四道质量门禁（gofmt / vet / race 测试 / 依赖校验）；打 v*.*.* tag 触发 build-and-release.yml：交叉编译、启动冒烟测试、打包 zip 与 SHA256SUMS，再由 softprops/action-gh-release 发布。

KEY POINT

两条触发路径

ci.yml 对 push 与 PR 全跑；build-and-release.yml 只在 tag 或手动触发，且 Release 步骤仅 tag 时执行。

BOUNDARY

可复现构建

四平台 -trimpath 交叉编译，-X main.version 注入 tag；产物含 web/ 与 README，二进制不含 audio.cpp。
