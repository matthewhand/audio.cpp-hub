Architecture · Internals

hub 内部架构

单进程内聚合 HTTP 路由与各管理器；实例、任务、下载、历史、音色与登记表各司其职，子进程与文件系统是唯一的进程外边界。

KEY POINT

每实例串行队列

TaskManager 为每个实例起一个单线程 executor，同实例任务排队执行，与引擎 busy 锁语义一致。

SEAM

进程内 vs 进程外

所有管理器同处一个 Go 进程；仅子进程与文件系统在进程外。
