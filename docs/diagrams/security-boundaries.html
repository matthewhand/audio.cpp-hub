ARCHITECTURE · SECURE PAVED ROAD

安全边界：哪些路径被放行，哪些在边界被拒绝

信任区从不可信的局域网客户端，经过「无鉴权」的 hub，到只监听回环的模型引擎。放行的是同源 JSON 请求；被拒绝的是跨站/非 JSON 变更与指向私网的下载地址。密钥与运行数据落在本机磁盘上。

KEY POINT

没有认证，也没有授权

hub 不校验任何身份：任何能连到端口的客户端都被视为受信（SECURITY.md 的威胁模型）。下图的校验仅用于降噪与防误用，不是访问控制——不要把它当作鉴权层。需要鉴权请在反向代理侧加 HTTPS + mTLS / Basic / OAuth。

PERMITTED vs FORBIDDEN

放行 / 拒绝

  • 放行：同源 POST /api/*（Origin 与 Host 同源、Content-Type: application/json）；/v1/* 仅接受 JSON，用于提取顶层 model。
  • 拒绝：跨站 Origin / null 或 Sec-Fetch-Site: cross-site 的变更 → CROSS_SITE_FORBIDDEN；text/plain 等非 JSON → UNSUPPORTED_MEDIA_TYPE。
  • 拒绝：/v1/* 的 multipart 无法提取 model → 400；download.go 对私网/链路本地/元数据地址 → DOWNLOAD_SSRF_BLOCKED；idvalidate 拒绝 ..、绝对路径、盘符。
