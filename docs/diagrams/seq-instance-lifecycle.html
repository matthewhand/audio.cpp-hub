SEQUENCE · 实例生命周期

模型实例生命周期

POST /api/instances 预占名称与端口并拉起子进程，/health 轮询（≤120s）转 READY；DELETE 停止子进程。

KEY POINT

名称 + 端口原子预占

Start 串行化：同一临界区内校验服务名全局唯一并登记占位实例，再从 instancePortBase 选空闲端口；随后写 run/<id>/server.json 并 os/exec 拉起子进程。

ASYNC NOTE

READY 由后台轮询置位

POST /api/instances 实际立即返回 200（status STARTING）；awaitReady 在后台每 1s 轮询 GET /health，≤120s 内 200 即置 READY，超时或进程退出转 FAILED。
