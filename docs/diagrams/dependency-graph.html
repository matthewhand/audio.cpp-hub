Go 文件与内嵌资源如何相互依赖

main.go 装配各管理器，api.go 是 HTTP 汇聚点；管理器共用 util.go 与 internal/ 校验层；models.json / model-packages.json 经 go:embed 编译进二进制。

KEY POINT

api.go 是汇聚点

全部 /api/* handler 与 /v1/* 代理入口都在 api.go；它依赖六个管理器与公共层，是唯一同时触及所有模块的文件。

COUPLING

task ↔ history

task.go 通过 TaskManager.history 调用 RecordTTS，TTS 的 taskId 即历史记录 id（上图强调的耦合边）；Go 包内不构成 import 环。
